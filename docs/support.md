# Support

## What Maintainers Support

Maintainers support:

- reproducible bugs in the scanner or CLI
- security-relevant false negatives
- high-impact false positives with clear operational cost
- policy/reporting regressions
- official rule pack issues

## What Is Best-Effort

The following are best-effort:

- integration examples
- community rule packs
- local environment issues outside documented install paths
- custom downstream workflows

## What Is Out Of Scope

The project does not guarantee:

- support for private downstream forks
- support for unpublished third-party schemas
- incident response for data the tool did not collect
- legal analysis of malware samples

## How To Ask For Help

Use:

- standard issues for bugs or improvements
- rule pack proposal templates for new rules
- private maintainer contact for vulnerabilities or
  scanner bypasses with security impact

When reporting a problem, include:

- exact version or commit
- command used
- input sample or minimal reproduction
- expected result
- actual result
